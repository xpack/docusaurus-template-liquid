The library is subject to continuous integration (CI) testing with every
push using [GitHub Actions](https://github.com/{{githubProjectOrganization}}/{{githubProjectName}}/actions).
The tests run on Ubuntu, macOS, and Windows.

Testing is conducted on both 32-bit and 64-bit bare-metal platforms,
including a selection of Arm Cortex-M, Cortex-A, and RISC-V, running
under QEMU.

The native tests run with the GCC and LLVM/clang compilers.

A workflow that runs the tests on all the supported platforms and
configurations can be triggered manually in the GitHub Actions interface, the
`Run all tests` workflow.

In the upstream project repository, the workflow can also be triggered
manually with:

```sh
xpm run trigger-workflow-test-all -C ~/Work/{{githubProjectOrganization}}/{{githubProjectName}}.git/tests
```

(this requires `curl` and the `GITHUB_API_DISPATCH_TOKEN` environment
variable to be set.)
