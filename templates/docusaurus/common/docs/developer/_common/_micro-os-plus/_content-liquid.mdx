## Satisfy dependencies

Navigate to the project folder:

```sh
cd ~/Work/{{githubProjectOrganization}}/{{githubProjectName}}.git
```

and execute the following commands:

```sh
npm install
npm --prefix tests install
xpm install -C tests
```

The last command installs the dependencies of the tests project, such as the
build tools. The toolchains required by each build configuration are
installed later, by the `install` actions, as described in
[Manual tests](#manual-tests); those actions also run `xpm install`, so
repeating it is harmless.

## Language standard compliance

The library is written in modern C++ and should be compiled with `-std=c++20`.

## Tests

The µOS++ testing strategy involves compiling the sources with
as many toolchains as possible and executing them on a wide
range of platforms.

### Host platforms

The tests may be executed on any of the supported host
platforms:

- GNU/Linux (x64 and arm64, **GLIBC>=2.28**); to execute the native
tests, a C++ development environment is required
(on Ubuntu install `build-essential`)
- macOS (>= **11.0**);
as C++ development environment use **Command Line Tools**
- Windows 10, Windows 11

### Semihosting

On embedded platforms, the applications interact with the
host via the
[semihosting mechanism](https://github.com/ARM-software/abi-aa/blob/main/semihosting/semihosting.rst),
defined by Arm and used with the same protocol on RISC-V.

### Toolchains

To enhance source code portability, the builds are repeatedly conducted
using various toolchains, including multiple versions of the same toolchain.

The following toolchains are used:

- gcc (native)
- clang (native)
- arm-none-eabi-gcc (Cortex-M, AArch32)
- aarch64-none-elf-gcc (AArch64)
- riscv-none-elf-gcc (RISC-V 32/64)
