### Test details

The tests are built and run for each platform and toolchain. To build and run
the native tests with the system compiler, use:

```sh
xpm run test -C ~/Work/{{githubProjectOrganization}}/{{githubProjectName}}.git/tests
```

The test programs are in the
[`tests/sources`](https://github.com/{{githubProjectOrganization}}/{{githubProjectName}}/tree/{{branchDevelopment}}/tests/sources)
folder, one folder for each program, with the sources in `src/`.

#### The test programs

| Program | What it tests |
| --- | --- |
| [`sample`](https://github.com/{{githubProjectOrganization}}/{{githubProjectName}}/blob/{{branchDevelopment}}/tests/sources/sample/src/main.cpp) | the main primitives of the library, in a short application |
| [`unit`](https://github.com/{{githubProjectOrganization}}/{{githubProjectName}}/blob/{{branchDevelopment}}/tests/sources/unit/src/main.cpp) | all the library functions, with the [µTest++](https://github.com/micro-os-plus/micro-test-plus-xpack) testing framework |
